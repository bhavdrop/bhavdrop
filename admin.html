Admin safety checklist

  • Only accounts with server-managed app_metadata.role = admin should access this console.
  • Never put a Supabase service-role key in website files.
  • Confirm payment manually before changing an order to paid/verified.
  • Deleting a product removes it from the catalog; consider setting it inactive instead if you add inventory/history features later.
